Multi-Area Setup with Local Sensors or Custom APIs

Outside Finland (FI), users typically already have a local Home Assistant sensor (such as Nord Pool HACS, ENTSO-E HACS, Tibber, Octopus, or Awattar) or their own API endpoint.

Step 1

Select Area & Currency

Choose your bidding area (e.g. SE1–SE4, NO1–NO5, DK1–DK2, EE, LV, LT, GER/DE, AT, PL, UK) and currency (AUTO or EUR, SEK, NOK, DKK, PLN, GBP, CHF, CZK, HUF, RON).

Step 2

Connect Local Sensor or API

Select your existing Home Assistant price sensor (ha_entity) to avoid rate limits and keep local taxes/tariffs, or enter a custom API URL (custom_api) with optional API key.

Step 3

Match Unit & Multiplier

Keep price_multiplier at 1.0 when your sensor already uses subunits (c/kWh, öre/kWh, øre/kWh, gr/kWh, p/kWh), or set e.g. 100.0 if converting major units per kWh.
